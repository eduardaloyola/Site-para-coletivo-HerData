# HerData

Site institucional do coletivo HerData, com foco em ciência de dados, tecnologia, protagonismo feminino e impacto social.

## Sobre o projeto

O HerData é um coletivo que conecta mulheres interessadas em ciência de dados, inteligência artificial, estatística e inovação com propósito. Este projeto apresenta a identidade do coletivo, seus valores, iniciativas e formas de participação.

## Tecnologias utilizadas

- React
- Vite
- TypeScript
- Tailwind CSS
- HTML
- CSS
- GitHub Pages

## Link do projeto

https://eduardaloyola.github.io/Site-para-coletivo-HerData/

## Objetivo

Promover a visibilidade do coletivo HerData, fortalecer a presença feminina na tecnologia e apresentar a comunidade, missão e iniciativas do grupo.
